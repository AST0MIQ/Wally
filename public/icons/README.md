# App icons

PWA / home-screen icons referenced by `public/manifest.webmanifest`.
These are generated in **Phase 4 (PWA & polish)**; until then the manifest
entries 404 harmlessly and installability is incomplete by design.

Required files:

| File                       | Size    | Purpose  |
| -------------------------- | ------- | -------- |
| `icon-192.png`             | 192×192 | any      |
| `icon-512.png`             | 512×512 | any      |
| `icon-maskable-512.png`    | 512×512 | maskable |
| `apple-touch-icon.png`     | 180×180 | iOS      |

iOS splash / launch images will also be added here (or under `public/splash/`)
in Phase 4.
